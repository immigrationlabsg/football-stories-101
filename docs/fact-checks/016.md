Rewritten from the earlier "Cantona v Owen" draft, which could not be used because Commons has no free photo of Cantona as a player; this was runner-up 2 in that draft's list of alternatives (design/drafts/otd-1104/alternatives.md, since deleted; it survives in git history before commit cedb331).

Method note: page fetching is blocked from this session (WebFetch cannot reach any host from here), so every claim was checked against web-search excerpts and the search tool's summaries of the pages named below, not by opening the full pages. Searches were restricted to named outlets where possible so each excerpt can be attributed. Cells marked "26 Oct check" use excerpts recorded by the earlier Cantona v Owen check the same day (draft log design/drafts/otd-1104/fact-check.md, deleted in commit cedb331); those excerpts are now restated in full in the rows below, so this log no longer depends on the deleted file. Third pass (26 October 2026, after an independent check): the December timing of the 2001 Ballon d'Or ("Six weeks later", "the same December") was searched again, once restricted to uefa.com and once to cnn.com (allowed_domains, one domain per search), and the row says so. CNN's 17 December 2001 report was added to the story's sources list. One body change: the closing reflection is now in the present tense (see the Reflection note).

Living-persons rule: Owen, Beckham, Riise, Figo and Keegan appear only in documented match events, award votes, transfers and shirt numbers. Nothing about private life, media work or off-field matters.
