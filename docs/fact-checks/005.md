## Quotes

- Shevchenko, "We dominated the game and I had a double chance that Dudek inexplicably saved. Football is beautiful for that reason. Never take anything for granted." This is verbatim from the FourFourTwo interview headline. It is a single, primary source.
- Dudek, "Jamie, let me study the penalties first, we've only got two minutes - please, let me concentrate now." This is verbatim as returned from liverpoolfc.com, "Jerzy's Istanbul shoot-out secrets" (also mirrored on legacy.liverpoolfc.com). It is a single original source; the wording should be rechecked against the live page.
