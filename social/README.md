# Social assets

The daily publish workflow writes one file per story here, `NNN.md`, with the
Facebook caption (and first comment), the Instagram caption and the Threads
post, plus copies of the 1080x1350 carousel cards under `cards/`. A preview of
the email as sent is in `NNN-email.md`.

Copy the text into Meta Business Suite (or any scheduler) each morning. Nothing
in this folder is published to the website.
